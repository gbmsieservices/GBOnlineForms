GREENBUCKS MANAGEMENT INC. — ONLINE FORMS

CONTENTS
- index.html
- style.css
- script.js
- assets/ (contains the four QR code PNG images)

HOW TO USE
1. Extract the ZIP file to a folder.
2. Keep index.html, style.css, script.js, and the assets folder together.
3. Open index.html in a web browser.
4. Click a form row to reveal its QR code and link.
5. Click the QR code or OPEN FORM to open the matching Google Form.

The QR codes are generated from the four supplied Google Forms URLs.
No backend, database, framework, or external JavaScript library is required.
Internet access is needed to open the Google Forms, but the website itself can be opened locally.
